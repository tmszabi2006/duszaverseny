# Winter expedition

The product is a mining expedition operated through code. A cinematic snowy mine entrance establishes the world; the working surfaces become clear, compact expedition instruments.

- Neutral charcoal and slate surfaces, aged copper/gold actions, glacier cyan robot optics, warm ivory text. The user requested removing the green cast from the background.
- Large condensed-feeling system display typography; normal readable system text; monospace only for code and coordinates.
- Full-bleed illustrated entrance on login, vertical expedition navigation on desktop, compact horizontal navigation on mobile.
- Map selection uses illustrated mine dossiers; the simulator uses stone-block relief, faceted ore and a tracked robot with an explicit direction marker.
- Snow uses three depth layers, wind and soft foreground flakes. Light snow is sparse; heavy snow has roughly seven times the density, larger foreground flakes and stronger wind. Stop animation in hidden tabs or reduced-motion mode. The working panels sit above the weather.
- Fifteen mine illustrations rotate deterministically by map ID; sorting and filtering do not change a map's illustration.
- Weather and sample programs use dark themed keyboard-accessible listboxes with descriptions, selection marks, Escape dismissal and repeat selection.
- All visuals ship locally. No third-party runtime fonts, images or animation dependencies.
- Preserve all real data and functionality; no fabricated ranks or progress.

## Surface modes
Login: Experience + Operate. Maps, simulation, editor, profile: Operate.

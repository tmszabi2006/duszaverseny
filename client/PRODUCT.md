# MineScript
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users and purpose
Hungarian programming competition participants program a mining robot, create maps and compare results.
## Capabilities and constraints
React frontend, Express/MySQL backend, shared MineScript interpreter. Preserve authentication, import/export, editor, execution, discovery rules, scoring, history and leaderboard. No invented game economies or progression. Work in the local repository; competition hosting remains separate.
## Brand commitments
MineScript name, Hungarian interface. User explicitly requests a complete modern redesign, unmistakable mining game identity, realistic winter atmosphere and improved snow. Colors and composition may change freely.
## Accessibility
Keyboard operation, responsive screens, readable code and map states, optional effects, reduced motion and background-tab suspension.
